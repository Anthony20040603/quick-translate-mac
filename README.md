# Quick Translate

Quick Translate 是 macOS 原生翻译工具。按住 **Command，快速连按两次 C**，读取本次复制的文字并弹窗翻译。只有这一个全局唤起快捷键。

## 首次使用

1. 打开 `build/QuickTranslate.app`。应用常驻屏幕顶部菜单栏。
2. 从屏幕顶部菜单「Quick Translate → 设置…」打开设置，使用「切换服务」选择阿里云百炼或智谱 GLM，再填写对应的 API Key 并保存。不同服务的设置和密钥分别保留在本机。
3. 在「系统设置 → 隐私与安全性 → 辅助功能」中允许 **QuickTranslate**（部分系统版本显示为「设备控制和数据访问」）。应用设置内提供授权入口；授权后会自动重新检查。
4. 在其他软件选中可以复制的文字，按住 ⌘，约 0.42 秒内连续按两次 C。
5. 主窗口仅有系统原生标题栏与整块译文显示区，不显示原文。顶部系统菜单可切换翻译方向、复制全部译文、停止生成、重新翻译和设置始终置顶；Esc 收起窗口。

如系统询问剪贴板访问权限，请允许。也可通过顶部「翻译 → 翻译剪贴板」发起翻译。若辅助功能已开启但快捷键没有响应，请退出并重新打开应用；开发中重新构建后，系统可能要求重新授权。

### 系统显示已允许，但应用仍提示未授权

本地临时签名会随可执行文件变化。系统可能仍显示旧版本的授权开关已开启，却拒绝当前版本。在系统设置的授权列表中选中旧的 QuickTranslate 项，使用列表下方的减号移除，再使用加号选择当前的 `build/QuickTranslate.app` 并开启。重新打开应用后检查权限状态。只反复切换开关或重启应用，未必能更新旧签名记录。

开发排查时，也可以只重置此应用的授权，再在系统提示中重新允许：

```sh
tccutil reset Accessibility com.anthony.quicktranslate.mac
```

这不会影响其他应用的权限。正式持续开发建议配置 Apple Development 签名证书；本机临时签名下，授权后应避免再次替换可执行文件。

## 第一阶段功能与边界

- SwiftUI 界面、AppKit 菜单栏与浮窗，无第三方依赖。
- 支持阿里云百炼 Qwen-MT Plus，以及智谱 GLM。百炼可填写业务空间的 Base URL，自动补全 `/chat/completions`。Qwen-MT 请求只传一条待译文本及翻译语言参数；Plus 流式结果按完整译文替换，避免文字重复拼接。
- 保留两次系统复制操作，等待本次剪贴板更新后再弹窗，不模拟按键，不直接读取其他软件选区。
- 仅当 Command 始终按住、两次 C 间隔为 60–420 毫秒且没有其他修饰键时触发。长按 C、释放 Command、其他按键会中止识别。
- 不监听本应用内的双击复制；系统启用安全键盘输入的场景可能无法监听。
- 默认自动中英互译，单次最多 30,000 字符；原文只保留在内存中供翻译和重试，不显示在界面上。
- 新请求替换旧请求；错误或中途断流不会显示为成功。可以从顶部菜单停止当前翻译或重新翻译。
- 仅支持本身可以复制的文本。图片、扫描 PDF 和禁止复制的软件需要后续 OCR 支持。
- 如果本次复制未更新剪贴板，在译文显示区提示，不自动发送旧剪贴板内容。
- 暂不包含术语表、翻译记忆、开机启动或自动更新。

## 百炼配置

在设置中选择「切换服务 → 阿里云百炼 · Qwen-MT Plus」，模型填 `qwen-mt-plus`。接口地址可以使用北京业务空间的 Base URL（`https://你的业务空间ID.cn-beijing.maas.aliyuncs.com/compatible-mode/v1`），或北京共享域名 `https://dashscope.aliyuncs.com/compatible-mode/v1`。填写同一地域、同一业务空间的百炼 API Key。切换服务不会把 GLM 密钥发送给百炼。

百炼按量计费；免费额度及有效期以控制台为准。若只希望使用免费额度，请在百炼控制台开启相应模型的「免费额度用完即停」。应用不会自动切换其他模型或服务，也不查询账户余额。官方说明：https://help.aliyun.com/zh/model-studio/new-free-quota

## 隐私与存储

- API Key 保存在 macOS 钥匙串中，与规范化后的接口地址绑定，不写入项目、偏好设置或日志。修改接口地址后需要为新地址重新填写密钥。
- 接口、模型及翻译方向通过系统偏好设置保存。
- 只有触发翻译时读取复制文本；所选原文经 HTTPS 发送到配置的服务。不会记录原文、译文、请求正文或密钥日志，也不会保存翻译历史。
- 关闭窗口会取消当前请求、收起窗口，应用继续在后台运行，可从菜单栏图标或 Dock 重新打开。完全退出请使用菜单栏中的「退出 Quick Translate」。

## 开发与构建

需要 macOS 14 或更高版本，以及支持 Swift 6 和 Icon Composer `.icon` 编译的新版 Xcode。构建脚本默认生成运行构建命令的 Mac 所用架构的应用。

可以在 Xcode 中打开 `Package.swift` 编辑和调试。调试运行的权限归属可能与独立 `.app` 不同，日常使用和快捷键验证请运行构建后的应用。

生成独立应用：

```sh
zsh scripts/build-app.sh
open build/QuickTranslate.app
```

运行测试：

```sh
zsh scripts/test.sh
```

构建脚本只生成本地应用，不压缩、不安装到「应用程序」、不发布。使用临时本机签名，尚未进行 Developer ID 签名或 Apple 公证。后续面向其他电脑分发时再配置正式签名。

## 简洁窗口（0.3.0）

主窗口使用普通 macOS 文档窗口：系统原生红黄绿按钮（关闭、最小化、缩放/全屏）、Quick Translate 标题，以及整块可选择复制的译文显示区。按系统外观自动显示浅色或深色，长文自动换行并纵向滚动。没有原文区、工具栏、底部状态栏或自定义窗口按钮。

默认宽度为 420 点，初始整窗高度约 180 点。译文增多时只自动增加高度，保持顶部位置；达到当前显示器可用高度的 40% 后不再自动增高，内容改为纵向滚动。每次新翻译重新计算高度，流式生成过程不会因译文修订反复缩小窗口。手动改变宽度后会重新排版，多屏之间移动会按所在屏幕重新计算上限。

- Quick Translate → 设置：模型、接口和密钥。
- 编辑 → 复制全部译文（⌘⇧C）；选中文字后也可用系统复制（⌘C）。
- 翻译 → 翻译剪贴板（⌘⇧V）、重新翻译（⌘R）、停止翻译（⌘.）及翻译方向。这些快捷键仅在应用内生效。
- 窗口 → 始终置顶：带勾选状态，并保存到下次启动。
- 窗口 → 最小化（⌘M）、缩放：系统原生窗口行为。

翻译加载与错误提示只在同一个文本显示区内呈现。⌘CC 全局快捷键保持不变。底层应用 ID 和钥匙串标识保持不变以保留配置，构建产物文件路径仍为 `build/QuickTranslate.app`。

每次按 ⌘CC 都以第二次 C 按下时的鼠标位置重新摆放窗口，即使窗口已经显示也会重新定位。窗口优先位于鼠标右下方，间隔 16 点；右侧或下方空间不足时分别向左、向上避让，确保窗口留在鼠标所在显示器的可用区域。取词等待期间移动鼠标不会改变本次定位，弹出后也不跟随鼠标移动。原生全屏状态下保留全屏布局。每次新翻译先恢复紧凑高度，再按译文展开至屏幕可用高度的约 40%。

## 图标（0.3.2）

应用图标直接使用 `Resources/Untitled.icon`，由 Xcode 的 `actool` 编译，保留 Icon Composer 的分层与玻璃效果，并同时生成旧系统兼容图标。原设计文件和 SVG 不会被构建脚本修改。

顶部菜单栏图标从 `01-Cobalt.svg`、`02-Aqua.svg` 的原始矢量路径叠加生成。0.3.3 起，两层均为完全不透明的实心形状，以约 0.65 点的透明细缝分开前后轮廓，实际造型尺寸为初版的 90%。系统仍会自动适配浅色与深色菜单栏；缝隙显示菜单栏本身的背景色。构建时生成 PDF 矢量资源，避免 Retina 显示模糊，无需额外安装绘图依赖。
